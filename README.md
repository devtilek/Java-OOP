# 🚀 Изучение Java OOP с нуля

Добро пожаловать в репозиторий, созданный для практического изучения объектно-ориентированного программирования (ООП) на Java. Проект построен на базе **Maven**.

## 🗺️ Карта тем (Навигация по репозиторию)

Каждая папка содержит отдельную тему ООП и свой подробный `README.md` файл с разбором задач. Кликай на тему, чтобы перейти к описанию:

* 📂 [**Классы и Объекты (ClassAndObject)**](./src/main/java/com/example/ClassAndObject) — Создание базовых классов, конструкторы, методы, массивы объектов.
* 📂 [**Инкапсуляция (Encapsulation)**](./src/main/java/com/example/Encapsulation) — Модификаторы доступа (`private`), скрытие данных, геттеры/сеттеры и логика управления массивами (Общежитие и Студенты).
* 📂 [**Наследование (inheritance)**](./src/main/java/com/example/inheritance) — Ключевое слово `extends`, переопределение методов (`@Override`), использование `super` на примере Car и User.

---

## 🛠️ Как запустить примеры

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Открой проект в IntelliJ IDEA как **Maven-проект**.
3. Переходи в нужную папку, находи файл с методом `main` и запускай ▶️.
