## 🗺️ Карта тем (Навигация по репозиторию)

Каждая папка представляет собой отдельный модуль, изучающий конкретный принцип ООП, и содержит свой собственный локальный `README.md` файл с разбором задач и теорией.

Кликай на тему, чтобы перейти к её описанию:

* 📂 [**Классы и Объекты (ClassAndObject)**](./src/main/java/com/example/ClassAndObject) — Основы: создание базовых чертежей классов, работа с ключевым словом `new`, использование пустых и параметризованных конструкторов, агрегация объектов.
* 📂 [**Инкапсуляция (Encapsulation)**](./src/main/java/com/example/Encapsulation) — Скрытие данных: использование модификатора доступа `private`, контролируемый доступ через геттеры и сеттеры, написание безопасной бизнес-логики внутри управляющих классов.
* 📂 [**Наследование (inheritance)**](./src/main/java/com/example/inheritance) — Повторное использование кода: связь классов через ключевое слово `extends`, работа с модификатором `protected` и переопределение методов (`@Override`).
* 📂 [**Абстрактные классы (abstractClasses)**](./src/main/java/com/example/abstractClasses) — Создание шаблонов: проектирование абстрактной логики с помощью модификатора `abstract` и обязательное переопределение бесформенных методов подклассами.
* 📂 [**Интерфейсы (Interfaces)**](./src/main/java/com/example/Interfaces) — Контракты поведения: полное разделение архитектуры от реализации с помощью `interface` и `implements`, работа со сложными структурами данных (Bean и Repository паттерны).
* 📂 [**Обработка исключений (tryCatch)**](./src/main/java/com/example/tryCatch) — Безопасность кода: перехват ошибок времени выполнения с помощью конструкции `try-catch`, обработка `NullPointerException` и контроль переполнения массивов данных.
* 📂 [**Динамические массивы (arrayList)**](./src/main/java/com/example/arrayList) — Работа с коллекциями: использование `ArrayList`, динамическое добавление и удаление элементов без ручного контроля индексов.

## 🛠️ Как запустить примеры локально

### Требования

* **JDK 25** — в `pom.xml` указаны `maven.compiler.source` и `maven.compiler.target` со значением `25`.
* **Git** — для клонирования репозитория.
* **IntelliJ IDEA** или другая IDE с поддержкой Java и Maven. В настройках проекта и Maven выбери JDK 25.

### Запуск

1. **Клонируй этот репозиторий:**
   ```bash
   git clone https://github.com/devtilek/Java-OOP.git
   cd Java-OOP
   ```
2. **Открой проект** в IntelliJ IDEA (или любой другой IDE) как **Maven-проект** (выбери корневой файл `pom.xml`, если среда разработки попросит подтверждение).
3. Переходи в интересующий тебя пакет внутри папки `src/main/java/com/example/`.
4. Находи класс с главной точкой входа (файл `Main.java` или специализированный `Main...Example.java`), нажимай на него правой кнопкой мыши и выбирай **Run** ▶️.
