# 📂 Тема: Наследование (Inheritance)

**Наследование** — это один из четырех фундаментальных принципов объектно-ориентированного программирования (ООП). Оно позволяет создать новый класс (класс-наследник) на основе уже существующего (родительского класса).

### 💡 Ключевые концепции этой темы:
* **Ключевое слово `extends`:** Используется в Java для указания родительского класса. Подкласс автоматически получает все поля и методы родителя (кроме `private`).
* **Модификатор `protected`:** Поля и методы с этим модификатором видны внутри текущего пакета, а также во всех классах-наследниках, даже если они находятся в других пакетах. Это идеальный баланс между скрытием данных (`private`) и полной открытостью (`public`).
* **Переопределение методов (`@Override`):** Механизм, с помощью которого дочерний класс может полностью изменить или дополнить поведение метода, объявленного в родительском классе, сохранив его сигнатуру (имя и параметры).

## 📝 Разбор практических задач

### 🧠 Теория к Задаче 1: Переопределение полиморфных методов
Когда дочерний класс наследует метод, возвращающий строку с описанием объекта (например, `getReady()`), он должен расширить эту строку собственными уникальными свойствами. Для этого внутри дочернего метода часто вызывают родительскую логику (или обращаются к `protected`-полям) и добавляют специфичные для конкретной модели детали.

#### 🚗 Спецификация задачи «Иерархия автомобилей» (`CarExample`)
**Родительский класс:** `Car`
* **Поля (`protected`):** `name` (String), `model` (String), `maxSpeed` (int), `year` (int), `volume` (double).
* **Метод:** `public String getReady()` — возвращает базовую информацию в формате:
  > *"Car Hyundai Accent with max speed and 2015 with engine volume 1.6 is ready to race"*

**Классы-наследники:**
* **`Toyota`**
    * Добавлено поле: `private String country`.
    * Переопределен метод `getReady()`. Ожидаемый вывод:
      > *"Toyota Supra with max speed and 2005 with engine volume 3.0 from Japan is ready to race"*
* **`Mercedes`**
    * Добавлено поле: `private String klass`.
    * Переопределен метод `getReady()`. Ожидаемый вывод:
      > *"Mercedes benz klass S-class with max speed and 2024 with engine volume 5.5 is ready to race"*

### 🧠 Теория к Задаче 2: Расширение логики и инкапсуляция массивов в подклассах
Иногда дочерний класс не просто хранит базовые типы данных, но и управляет сложными структурами (например, массивами строк), которых не было у родителя. В таких случаях стандартные сеттеры для массивов не используются, так как они могут нарушить целостность данных. Вместо этого пишутся кастомные бизнес-методы (`add...`), которые инкапсулируют логику добавления элементов по индексу, защищая массив от переполнения.

#### 👥 Спецификация задачи «Пользователи и Сотрудники» (`UserExample`)
**Родительский класс:** `User`
* **Поля (`protected`):** `id` (int), `login` (String), `password` (String), `name` (String).
* **Метод:** `public void getInfo()` — выводит в консоль базовые параметры (`id`, `login`, `password`, `name`).

**Класс-наследник:** `Staff` (Преподавательский состав)
* **Добавленные поля:**
    * `private int salary` — зарплата сотрудника.
    * `private String[] subjects = new String[100]` — фиксированный массив предметов, которые ведет преподаватель.
    * `private int indexOfSubjects = 0` — внутренний счетчик-указатель для добавления предметов.
* **Специальные методы:**
    * `public void addSubject(String subject)` — заменяет стандартный сеттер. Позволяет поочередно добавлять новый предмет в массив `subjects` и автоматически увеличивать `indexOfSubjects`.
    * `public void getSubjects()` — выводит в консоль только заполненную часть предметов из массива.
    * `public void getInfo()` — **переопределенный метод**. Сначала выводит базовую информацию о пользователе, затем зарплату преподавателя, после чего запускает внутренний метод для распечатки списка всех его предметов.
