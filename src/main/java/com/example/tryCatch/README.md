# 📂 Тема: Обработка исключений (try-catch)

**Исключения (Exceptions)** — это ошибки, которые возникают во время выполнения программы. Конструкция `try-catch` позволяет перехватывать эти ошибки и обрабатывать их, чтобы программа не «падала» аварийно.

### 💡 Ключевые концепции этой темы:
* **Блок `try`:** Внутри этого блока пишется код, который потенциально может содержать или вызвать ошибку.
* **Блок `catch`:** Этот блок срабатывает только тогда, когда внутри блока `try` произошла конкретная ошибка. Программа выполняет безопасный сценарий обработки.
* **`NullPointerException` (NPE):** Ошибка, которая происходит, когда программа пытается обратиться к методам или свойствам объекта, который равен `null` (т.е. пустой, не созданный в памяти).

## 📝 Разбор практических задач

### 🧠 Теория к ex1: Безопасная работа с пустыми объектами клинтов (`BookExample`)
При работе со списками и базами данных часто попадаются незаполненные карточки или пустые элементы массива. Вместо остановки работы всего приложения, мы оборачиваем логику вывода в `try-catch`, аккуратно сигнализируя пользователю о пустой ячейке.

#### 📚 Спецификация задачи «Библиотека и книги» (`ex1`)
* **Класс Book:** Содержит `id`, `name`, `author`. Метод `getData()` обернут в блок `try-catch` для перехвата `NullPointerException`. Если поля пустые, выводится сообщение *"кітап пустой"*.
* **Класс Library:** Содержит массив из 3 книг.
    * Метод `addBook(Book book)` отслеживает количество элементов. Если лимит превышен, выдает предупреждение *"Library is full!"*.
    * Метод `printAllBooks()` выводит всю библиотеку. Если в ней совсем нет книг, выводится *"Lirarby is Empty!"*.
