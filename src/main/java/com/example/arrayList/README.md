# 📂 Тема: Динамические массивы (ArrayList)

**ArrayList** — это подкласс каркаса Collections в Java, который представляет собой автоматически расширяемый массив. В отличие от стандартных массивов (`Type[]`), у `ArrayList` нет фиксированной длины, что позволяет динамически добавлять и удалять элементы.

### 💡 Ключевые концепции этой темы:
* **Динамичность:** Размер массива увеличивается автоматически при добавлении новых элементов.
* **Основные методы:**
    * `.add(element)` — добавляет элемент в конец списка.
    * `.get(index)` — возвращает элемент, находящийся на указанной позиции.
    * `.remove(index)` — удаляет элемент по его индексу со сдвигом остальных элементов.
    * `.size()` — возвращает текущее количество заполненных элементов в списке.

## 📝 Разбор практических задач

### 🧠 Теория к ex1: Агрегация динамических списков
В этой задаче мы уходим от фиксированных массивов (как это было в задаче с `Dorm` или `Library`) и связываем сущности через `ArrayList`. Студент может посещать неограниченное количество курсов (`ArrayList<String>`), а академическая группа может включать любое число студентов (`ArrayList<Student>`).

#### 🎓 Спецификация задачи «Группы и Студенты» (`ex1`)
* **Класс Student:** Хранит имя студента и список его курсов.
    * `addCourse(String course)` — добавляет курс.
    * `removeCourse(int index)` — безопасно удаляет курс по индексу.
    * `getAllCourses()` — выводит в консоль список всех курсов.
* **Класс Group:** Управляет списком студентов внутри академической группы.
    * `getAllStudents()` — распечатывает имена всех студентов в группе через цикл.
    * `getStudent(int index)` — возвращает конкретного студента по его позиции в списке.
