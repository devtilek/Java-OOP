# 📂 Тема: Абстрактные классы (Abstract Classes)

**Абстрактный класс** — это класс-шаблон, который нельзя использовать для создания объектов напрямую (нельзя написать `new Food()`). Он создается для того, чтобы определить общий контракт, структуру и базовое поведение для всех своих будущих классов-наследников.

### 💡 Ключевые концепции этой темы:
* **Модификатор `abstract`:** Указывается перед ключевым словом `class` и перед методами.
* **Абстрактные методы (`public abstract double getCalories()`):** Это методы без тела (без `{}`). Они содержат только сигнатуру. Каждый обычный (не абстрактный) класс-наследник **обязан** переопределить эти методы и написать их конкретную реализацию.
* **Полиморфизм:** Мы можем создать массив абстрактного типа (например, `Food[] menu`) и положить туда разные объекты (`Burger`, `Cola`). При вызове `getCalories()` Java сама поймет, по какой формуле считать калории для каждого продукта.

## 📝 Разбор практических задач

### 🧠 Теория к Задаче 1: Полиморфный расчет характеристик
Когда мы описываем абстрактную сущность «Еда» (`Food`), мы знаем, что у любой еды есть вес и название, и её калорийность можно как-то посчитать. Но общую формулу калорий для абстрактной еды написать невозможно — для бургера и газировки формулы абсолютно разные. Поэтому метод расчета делается абстрактным, а наследники реализуют свои уникальные формулы.

#### 🍔 Спецификация задачи «Подсчет калорий в еде» (`FoodExample`)
**Абстрактный класс:** `Food`
* **Поля (`protected`):** `name` (String), `weight` (int).
* **Методы:**
    * `public abstract double getCalories();` — абстрактный метод без реализации.
    * `public void getData()` — обычный метод, выводит в консоль данные:
      > *"Food: [имя] with [калории] calories is done!"*

**Классы-наследники:**
* **`Burger`**
    * Добавленные поля: `private int meatAmount`, `private int meatType`.
    * Реализация `getCalories()`:
        * Если `meatType == 1`, то формула: `weight * meatAmount * 1.5`
        * Если `meatType == 2`, то формула: `weight * meatAmount * 1.2`
* **`Cola`**
    * Добавленное поле: `private int colaType` (с сахаром или без).
    * Реализация `getCalories()`:
        * Если `colaType == 1`, то формула: `weight * 3`
        * Если `colaType == 2`, то формула: `weight * 1.1`

### 🧠 Теория к Задаче 2: Общие профили пользователей через абстракцию
В любой системе есть пользователи (`User`), но в реальности "просто пользователя" не существует — это всегда либо преподаватель, либо студент. Абстрактный класс собирает общие поля (логин, пароль), а наследники расширяют профиль своими специфичными данными и реализуют абстрактный метод получения информации `getUserInfo()`.

#### 👥 Спецификация задачи «Система пользователей» (`UserAbstractExample`)
**Абстрактный класс:** `User`
* **Поля (`protected`):** `id` (int), `login` (String), `password` (String).
* **Метод:** `public abstract String getUserInfo();` — абстрактный метод для получения карточки пользователя.

**Классы-наследники:**
* **`Teacher`** (Преподаватель)
    * Добавленные поля: `private String name`, `private String surname`, `private String status`, `private String[] subjects = new String[100]`, `private int indexOfSubject = 0`.
    * Особенность: Для `subjects` и `indexOfSubject` **геттеры и сеттеры не создаются**.
    * Методы:
        * `public boolean addSubject(String subject)` — добавляет предмет в массив и сдвигает счетчик.
        * `public String getSubjects()` — собирает и возвращает строку со всеми предметами учителя.
        * `public String getUserInfo()` — реализует абстрактный метод, возвращая полную строку с личными данными, статусом и списком предметов.
* **`Student`** (Студент)
    * Добавленные поля: `private String name`, `private String surname`, `private String group`, `private double gpa`.
    * Методы:
        * `public String getUserInfo()` — реализует абстрактный метод, возвращая карточку студента со всеми его данными и успеваемостью (GPA).
