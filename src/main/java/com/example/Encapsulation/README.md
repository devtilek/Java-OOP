# 📂 Тема: Инкапсуляция (Encapsulation)

**Инкапсуляция** — это сокрытие внутреннего состояния объекта от прямого вмешательства извне, а также объединение данных и методов для работы с этими данными в одном классе.

### 💡 Ключевые концепции этой темы:
* **Модификатор `private`:** Делает поля класса абсолютно невидимыми из других классов. Никто не может напрямую изменить или прочитать данные (например, написать `student.gpa = 99.0`).
* **Геттеры и Сеттеры (Getters / Setters):** Публичные методы (`public`), которые выступают «посредниками» для доступа к `private`-полям.
    * **Getter** (например, `getGpa()`) — безопасно возвращает значение поля.
    * **Setter** (например, `setGpa(double gpa)`) — позволяет изменить значение, предварительно проверив его на корректность (например, что GPA не может быть отрицательным или больше 4.0).
* **Защита от NullPointerException (NPE):** При работе с массивами инкапсулированных объектов (особенно после их удаления, когда в ячейке оказывается `null`), перед вызовом любых методов объекта **обязательно** нужно делать проверку `if (item != null)`.

## 📝 Разбор практических задач

### 🧠 Теория к Задаче: Моделирование логики бизнес-процессов с защитой данных
Когда мы управляем сущностями (например, жильцами в общежитии), мы не должны давать внешнему коду напрямую переписывать массив. Все действия — добавление, удаление, поиск лидера — инкапсулируются внутри управляющего класса (`Dorm`). Сам класс следит за тем, чтобы операции проходили безопасно, не ломая структуру данных.

#### 🏢 Управление данными: Студенты и Общежитие (`Student`)
* **Класс Student:** Данные полностью инкапсулированы (поля `private`). Доступ открыт через `getId()`, `getGpa()`, `getName()`, `getSurname()`.
* **Класс Dorm (Общежитие):** Содержит скрытый массив `private Student[] students`.
* **Бизнес-логика внутри Dorm:**
    * `addStudent(Student student)` — добавление студента на свободное место.
    * `printStudents()` — безопасный вывод списка жильцов (пропускает пустые/выселенные ячейки `null`).
    * `removeStudentFromDorm(int id)` — выселение студента. Метод ищет объект по его `getId()`, заменяет ячейку на `null` и возвращает статус операции (`true`/`false`).
    * `getMaxGpa()` — алгоритм поиска студента с наивысшим баллом. Пробегается по массиву, сравнивает инкапсулированные значения `getGpa()` и возвращает объект самого успешного студента.
