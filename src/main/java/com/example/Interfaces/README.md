# 📂 Тема: Интерфейсы (Interfaces)

**Интерфейс** — это полностью абстрактный класс-контракт, который описывает исключительно *то, что класс должен делать*, но не определяет *как именно* он должен это делать.

### 💡 Ключевые концепции этой темы:
* **Ключевое слово `interface`:** Создает абстрактный контракт. Все методы в нём по умолчанию являются публичными и абстрактными (`public abstract`).
* **Ключевое слово `implements`:** Применяется классами для реализации интерфейса. Каждый обычный класс обязан переопределить все методы интерфейса.
* **Гибкость архитектуры:** Интерфейсы позволяют отделить общую логику приложения от конкретной технической реализации и объединять разные классы под одним типом.

## 📝 Описание практических задач

### 🧠 Теория к ex1: Контракт сотрудника (`WorkerExample`)
Интерфейс задает минимальные требования к сущности, которая хочет считаться «Работником». Класс `Staff` обязуется предоставить свою зарплату и карточку данных.
* **Worker:** Интерфейс с сигнатурами `String getData()`.
* **Staff:** Реализует интерфейс, хранит приватные поля (`id`, `name`, `surname`, `salary`) и собирает информацию о работнике в одну строку через обычное сложение `+`.

---

### 🧠 Теория к ex2: Фильтрация данных в массиве (`UserBeanExample`)
В промышленной разработке через интерфейсы описывают сервисы для работы с данными. Здесь класс-реализация скрывает внутри себя массив объектов и предоставляет методы для поиска.
* **UserBean:** Задает методы `getAllUsers()`, `getUsersByName(String name)` и `getBySurname(String surname)`.
* **UserBeanImpl:** Хранит массив `User[] users` и счетчик `indexOfUser`. Реализует циклы для поиска и вывода в консоль подходящих под критерии пользователей.

---

### 🧠 Теория к ex3: Управление банковскими счетами (`BankExample`)
Самая сложная задача, моделирующая реальное приложение. Интерфейс выступает пультом управления банком, а класс реализации инкапсулирует сложные операции (проверку на свободное место, удаление элементов и защиту от пустых ячеек `null`).
* **BankAppInterface:** Методы для добавления счета, вывода списка, поиска аккаунта по ID и его удаления.
* **BankApplication:** Содержит массив `Account[] accounts`. Реализует безопасное выселение/удаление аккаунта (присвоение ячейке значения `null`) и точный поиск объектов по их уникальному ID без путаницы с индексами массива.
