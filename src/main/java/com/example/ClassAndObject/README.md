# 📂 Тема: Классы и Объекты (ClassAndObject)

**Классы и Объекты** — это фундамент всего объектно-ориентированного программирования.

### 💡 Ключевые концепции этой темы:
* **Класс (Class):** Это чертеж, шаблон или «тип данных», который описывает, какими свойствами (полями) и поведением (методами) будет обладать объект.
* **Объект (Object):** Это конкретный экземпляр класса, созданный в памяти компьютера с помощью ключевого слова `new`. У каждого объекта свои уникальные значения полей.
* **Конструктор (Constructor):** Специальный блок кода, похожий на метод, который вызывается при создании объекта. Он инициализирует начальное состояние объекта.
    * *Пустой конструктор* создает объект с дефолтными значениями.
    * *Параметризованный конструктор* позволяет передать значения полей сразу при создании.
* **Взаимодействие классов:** Объекты могут содержать внутри себя массивы других объектов (связь «один ко многим»), выстраивая сложную логику приложения.

## 📝 Разбор практических задач

### 🧠 Теория к Задаче 1 и 2: Создание сущностей и работа с состоянием
В базовых задачах мы учимся описывать структуры данных реального мира (телефон, студент) через поля класса, создавать их через различные конструкторы и писать методы, которые красиво собирают и возвращают информацию об объекте в виде строки.

#### 📱 1. Класс Phone (Телефон)
* **Поля:** `String name`, `String model`, `int price`.
* **Что реализовано:** Пустой конструктор, параметризованный конструктор и метод `getInfo()`, возвращающий полную информацию о телефоне.

#### 🎓 2. Класс Student (Студент)
* **Поля:** `int id`, `String name`, `String surname`, `double gpa`.
* **Что реализовано:** Инициализация через конструкторы и метод `getStudentInfo()` для вывода карточки студента с его текущим средним баллом.

### 🧠 Теория к Задаче 3 и 4: Агрегация объектов и управление массивами
Классы становятся мощным инструментом, когда начинают ссылаться друг на друга. Например, один объект (Клуб или Библиотека) может хранить в себе **массив** других объектов (Игроков или Книг). Здесь важно научиться управлять индексами массива и безопасно наполнять его.

#### ⚽ 3. Связь классов: Игрок и Клуб (`soccerExample`)
* **Player:** Хранит данные футболиста. Переопределен метод `toString()`.
* **Club:** Содержит название и массив объектов `Player[] players`. Метод `getClubInfo()` выводит данные клуба и циклом распечатывает состав команды.

#### 📚 4. Логика добавления: Книги и Библиотека (`BookExample`)
* **Book:** Модель книги с уникальным ID, названием и автором.
* **Library:** Содержит фиксированный массив `Book[] books = new Book[3]` и внутренний счетчик `int i = 0`. Метод `addBook(Book book)` поочередно добавляет книги в массив по текущему индексу.
